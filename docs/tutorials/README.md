# Tutorials

Lessons, in order. Each one has a single outcome, runs on a laptop with no
sensors attached, and tells you what you should be seeing at every step. If
something else appears on your screen, that is a bug in the tutorial — open an
issue.

1. **[Your first run without hardware](first-run.md)** — install the agent, watch
   simulated sensors being read, make a rule fire and find it in the history.
   About ten minutes.
2. **[Watching an incident open and close](first-incident.md)** — write a rule
   of your own, see repeated firings group into one incident, acknowledge it,
   and watch it resolve by itself. About fifteen minutes, and it follows on
   from the first.

These are lessons, not recipes. They take the shortest path to something
working, and they skip the alternatives on purpose — when you want to do a
specific thing your own way, the [how-to guides](../how-to/README.md) are the
place, and every option is in the [reference](../reference/README.md).
