# edgesentinel documentation

Four kinds of documentation, kept apart on purpose. Each answers a different
question, and a page that tries to answer two answers neither well. The split
follows [Diátaxis](https://diataxis.fr/).

| If you want to… | Go to | Because |
|---|---|---|
| learn by doing | [Tutorials](tutorials/README.md) | a lesson with a known outcome, on a machine with no hardware |
| get something done | [How-to guides](how-to/README.md) | steps for a goal you already have |
| look something up | [Reference](reference/README.md) | every option, field and contract, stated plainly |
| understand why | [Explanation](explanation/README.md) | the reasoning behind the design |
| know what was decided, and when | [Decision records](adr/README.md) | one file per architectural decision, dated |

New here? [Your first run without hardware](tutorials/first-run.md) takes about
ten minutes and needs nothing but Python.
